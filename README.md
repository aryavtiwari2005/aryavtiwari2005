## 🚀 stuff i've built

### [🎵 Guava Music](https://github.com/aryavtiwari2005/guava-music) — `Node.js` `AWS` `Collaborative Filtering`
A music streaming backend built for actual scale. 1k+ concurrent users, 50M+ track library, and a recommendation engine using collaborative filtering that gets it right 90% of the time. Before AI recommendations were just a `pip install` away.

---

### [📹 AllCall](https://github.com/aryavtiwari2005/allcall) — `Node.js` `EJS` `WebRTC`
No sign-up. No download. No drama. Just open the URL and video chat. Peer-to-peer rooms with zero friction, because joining a call shouldn't feel like filing taxes.

---

### [🎙 Python Voice Assist](https://github.com/aryavtiwari2005/python-assist) — `Python` `NLP`
A voice assistant built before everyone had one. Handles tasks through speech — kind of like Siri, but you can actually read the source code.

---

### [💻 Code Editor](https://github.com/aryavtiwari2005/code-editor) — `JavaScript`
A browser-based code editor. Write code in a tab, like a person with too many tabs open already.
